A model-free geolocation entry: it answers every photo in a trial with one fixed point, the distribution centre of the public practice set, because an unanswered photo scores the maximum possible error.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
